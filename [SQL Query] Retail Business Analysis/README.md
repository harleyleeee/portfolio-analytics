# Retail Business Analysis — SQL

## Overview

This project uses SQL to analyze a relational retail dataset across sales, customers, products, and store operations.

The analysis focuses on:

- Sales performance
- Customer & market analysis
- Product & profitability analysis
- Store & operations analysis
- Potential store cannibalization

## Business Interpretation

The project demonstrates how SQL can be used not only to retrieve data, but also to support business decision-making.  
The findings highlight differences in customer value, product profitability, store productivity, and potential expansion risks, showing the importance of evaluating business performance through multiple KPIs rather than relying on a single metric.

## Dataset

The dataset consists of four main tables:

- `sales`
- `customers`
- `products`
- `stores`

The `sales` table serves as the central transaction table and is joined with customer, product, and store data for business analysis.

## SQL Skills

`JOIN` · `GROUP BY` · `CTE` · `ROW_NUMBER()` · `DENSE_RANK()` · `PARTITION BY` · `NTILE()` · `DATEDIFF()` · Conditional Aggregation · KPI Calculation
